# Frontend Engineering Practice

This repository is a space for building and strengthening my frontend development skills through practical projects and exercises.

## About

Originally created during my third year of university for a web development course, this repository was intended to host my first portfolio website. I am now repurposing it as a place to continue learning and practicing frontend engineering after graduating as a software engineer.

## Focus Areas

- HTML and semantic markup
- CSS and responsive layouts
- JavaScript fundamentals and browser interactions
- Small projects that apply these concepts

## Purpose

The goal is to learn by building, revisit the fundamentals, and track my progress over time. The contents will grow as I add new exercises and projects.
